# Test-Project

A Node.js starter for a TypeScript and Next.js app. Environment variables are loaded with [`dotenv`](https://github.com/motdotla/dotenv).

## Tech stack

- **Runtime:** Node.js
- **Language:** TypeScript (planned)
- **Framework:** Next.js (planned)
- **Config:** dotenv

## Getting started

**Requirements:** Node.js 18 or later.

```bash
npm install
```

There is no app entry yet (`index.js` / Next.js app). Add your source after install.

Load environment variables in Node with:

```js
require("dotenv").config();
```

Create a `.env` file in the project root for local secrets. Do not commit that file.
